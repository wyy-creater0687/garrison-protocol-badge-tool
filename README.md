# 卫戍协议刷标工具（不稳定，纯测试）

**用途：刷《明日方舟》「卫戍协议 · 极速模拟」的蚀刻章（策略彩色角标）。**

同一策略连续通关 6 次 → 出彩色角标（蚀刻章）→ 自动换下一个策略；
一整页都出彩标了 → 自动往下滑一页继续；滑到底 → 程序自己停。

> ⚠️ 纯测试版，不稳定，仅供学习交流。使用前请自行评估风险。

## 用法

1. 解压压缩包，得到 `测试1.0\` 文件夹；
2. 打开模拟器（MuMu 模拟器 12，1920×1080 横屏）和游戏，进到「卫戍协议」主界面（能看到「极速模拟」按钮那一页）；
3. 双击 `测试1.0.bat` → 选设备（1 模拟器 / 2 PC 端）→ 选模式（一般用 2：标准·彩色角标，同一策略 6 次）；
4. 之后不用管，关掉黑窗口即停止。

详细说明见包内 `使用说明.txt`。

## 选策略逻辑

按列表顺序「左→右、上→下」逐格点开检查：

- 面板显示「已通过模拟 6 次」→ 跳过（并记进 `checked_full.json`，下次不再点）；
- 面板里有「禁用 / 不可用」→ 跳过（红标，本局随机不可用）；
- 剩下的第一格没满 6 次、也没被禁用 → 选中它，点「确认选择」开打；
- 一整页都跳过 → 自动往下滑一页（约 4 行）；滑到底 → 全部完成。
